# 2026 年 9 月茶誌內容來源

`blog-01.txt` 至 `blog-10.txt` 保存一百篇原創短文的可編輯正文，每篇以 `@@` 開始；欄位依次為網址名稱、標題、分類、兩個配圖名稱、來源編號及延伸閱讀路徑。

`blog-manifest.json` 提供文章索引，`guides.json` 保存六篇指南，`chapters-extra.json` 保存新增的茶學章節內容。公開頁面是儲存庫內的靜態 HTML；修改這些來源檔案不會自動改寫公開頁面。

配圖位於 `assets/journal-v5/`。二十幅新插畫按文章內容搭配使用；一百篇文章各有兩幅圖，共二百個配圖位置。每幅另備較小的列表版本，圖片生成記錄與配圖同存。

編輯時保留來源連結，避免把文學場景當成實地紀錄，或把初步研究寫成確定功效。發佈前須同步更新全文搜尋與網站地圖，並檢查頁面路徑、圖說及手機閱讀效果。
